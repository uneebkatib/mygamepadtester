## GENERAL IMAGE GUIDELINES

### Style Consistency:
- Use consistent lighting across all guide photos
- Maintain clean, professional aesthetic
- Use dark workbench or white background
- Include brand colors subtly (Xbox green, PlayStation blue, Nintendo red)
- Ensure 16:9 aspect ratio for hero images
- Use 4:3 or 1:1 for step-by-step photos

### Technical Requirements:
- Minimum 1920x1080 resolution for hero images
- Minimum 1280x720 for step photos
- PNG or high-quality JPEG (90%+)
- Properly compressed for web (under 500KB if possible)
- Alt text for accessibility and SEO

### Branding:
- Include mygamepadtester.com logo subtly in hero images
- Use consistent color scheme (orange #DA7756 accent)
- Professional, trustworthy aesthetic
- Avoid cluttered or amateur-looking images

### Image File Naming:
Follow SEO best practices:
- `xbox-one-stick-drift-hero.jpg`
- `xbox-one-stick-drift-soldering-setup.jpg`
- `ps5-hdmi-port-close-up.jpg`
- `joycon-drift-before-after.jpg`

## AI IMAGE GENERATOR PROMPTS (READY TO USE)

### For DALL-E 3:
Simply copy the prompts above as-is. DALL-E 3 works best with descriptive, conversational prompts.

### For Midjourney:
Add these parameters to the end of each prompt:
```
--ar 16:9 --v 5 --q 2 --style photographic
```
Example: "Professional photo of disassembled Xbox One controller... --ar 16:9 --v 5 --q 2 --style photographic"

### For Stable Diffusion:
Add negative prompts:
```
Negative prompt: blurry, low quality, distorted, amateur, cluttered, dark, overexposed, watermark, text
Steps: 30, Sampler: DPM++ 2M Karras, CFG scale: 7
```
